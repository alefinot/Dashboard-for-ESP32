# Plain-English pinout sheet (drawing aid)

Everything here is read out of the board itself (`hardware/dashboard-plusplus-carrier.kicad_pcb`,
generated by `hardware/scripts/make_pcb.py`). The long technical reference stays in
`README.md` — section *Hardware Pinout Matrix*.

Useful when sketching a new layout: the **label** column is the name used in the code and on
the silkscreen; what you call each block on your drawing is up to you.

## 1. Board frame (fixed geometry)

| Item | Value |
|---|---|
| Board outline | 85.0 × 55.0 mm — KiCad coords x 10→95, y 10→65 |
| View used everywhere | top view: x grows to the right, y grows **down** |
| ESP32 DevKit header rows | near row y = 20.00, far row y = 45.40 (25.4 mm apart), 15 pins each, pitch 2.54 |
| Pin 1 of both rows (square pad) | x = 22.00 — that end is the DevKit's **USB end** |
| DevKit body hanging underneath | x 13.6→67.6, y 18.6→46.8 |
| Antenna keep-out (no copper, any layer) | x 48.96→68.2, y 22.0→43.4 |
| Display socket | along the bottom edge, y = 61.50, pin 1 at x = 25.00 |
| Parts on the **underside** | `J10a`, `J10b` (DevKit sockets), `U4` (LM2596 module) |

| debug / serial plug (TX, RX, GND, 5V) | `J13` |

## 3. ESP32 DevKit sockets

Positions counted from the **USB end** of the dev board (pin 1 = square pad).
Silkscreen note on the board says *CHECK SILK* — clones differ, verify against your module.

**Near row (top, `J10a`)**

| pos | silk | net | used for |
|---|---|---|---|
| 1 | VIN | `V5` | +5 V supply in |
| 2 | GND | `GND` | 0 V |
| 3 | IO13 | `SPARE_D13` | spare |
| 4 | IO12 | `TFT_BL` | display backlight (must be LOW at reset — `R12` pulls it down) |
| 5 | IO14 | `TFT_RST` | display reset |
| 6 | IO27 | `TFT_DC` | display data/command |
| 7 | IO26 | `SPARE_D26` | spare |
| 8 | IO25 | `TRIP_BTN` | trip reset button to GND |
| 9 | IO33 | `HALL` | speed sensor (filtered) |
| 10 | IO32 | `FUEL_SNS` | fuel sender |
| 11 | IO35 | `BAT_SNS` | battery voltage |
| 12 | IO34 | `LDR_SNS` | light sensor |
| 13 | IO39 | — | **not connected** |
| 14 | IO36 | `COOL_SNS` | coolant NTC |
| 15 | EN | `EN` | enable / reset (also on `J16`) |

**Far row (bottom, `J10b`)**

| pos | silk | net | used for |
|---|---|---|---|

| 19 | IO2 | `SPARE_D2` | spare |

| 21 | IO16 | `GPS_RX` | GNSS module TX → ESP |
| 22 | IO17 | `GPS_TX` | ESP → GNSS module RX (idle) |

## 4. Display socket `J3` (16 pins, pin 1 = VCC, along the bottom edge)

| pin | silk | net | | pin | silk | net |
|---|---|---|---|---|---|---|
| 1 | VCC | `V5` | | 9 | SDO | *(open)* |
| 2 | GND | `GND` | | 10 | T_CLK | *(open)* |
| 3 | CS | `TFT_CS` | | 11 | T_CS | *(open)* |
| 4 | RST | `TFT_RST` | | 12 | T_DIN | *(open)* |
| 5 | DC | `TFT_DC` | | 13 | TPEN | *(open)* |
| 6 | SDI | `TFT_MOSI` | | 14 | T_DO | *(open)* |
| 7 | SCK | `TFT_SCK` | | 15 | SD | *(open)* |
| 8 | LED | `TFT_BL` | | 16 | NC | *(open)* |

Touch and SD pads are deliberately left unconnected (no MISO in the firmware, touch removed in 1.3.6).

## 5. Vehicle & accessory connectors

| label | pins (silk → net) |
|---|---|
| `J1` power in | 1 = `DC_IN` (+12 before fuse) · 2 = `GND` |
| `J9` speed/hall | 1 `+V` = `HALL_VCC` · 2 `SIG` = `HALL_SIG` · 3 `G` = `GND` |
| `J17` ignition | 1 `IGN` = `IGN_12` · 2 `GND` = `GND` |
| `J5` coolant NTC | 1 `SIG` = `COOL_SNS` · 2 `GND` = `GND` |
| `J7` fuel sender | 1 `SIG` = `FUEL_SNS` · 2 `GND` = `GND` |
| `J6` light sensor | 1 `SNS` = `LDR_SNS` · 2 `GND` = `GND` (LDR solders here too) |
| `J14` trip button | 1 `TRIP` = `TRIP_BTN` · 2 `GND` = `GND` |
| `J8` GNSS module | 1 `SDA` = `SPARE_D21` · 2 `SCL` = `SPARE_D22` · 3 `5V` = `V5` · 4 `GND` · 5 `RX` = `GPS_TX` · 6 `TX` = `GPS_RX` |
| `J13` debug | 1 `TX` = `DBG_TX` · 2 `RX` = `DBG_RX` · 3 `GND` · 4 `5V` = `V5` |
| `J15` spare | 1 `D26` · 2 `SDA` · 3 `SCL` · 4 `D19` · 5 `D15` · 6 `GND` |
| `J16` reset | 1 `EN` · 2 `GND` |
| `J11` spare 2×3 | 1 `GND` · 2 `V5` · 3 `SPARE_D26` · 4 `SPARE_D13` · 5 `IGN_12` · 6 `SPARE_D2` |
| `JP1` hall supply | 1 `5V` = `V5` · 2 `SEL` = `HALL_VCC` · 3 `12V` = `DC_12` (jumper picks the sensor supply) |

## 6. Small parts, what each one is for

| label | value | between | purpose |
|---|---|---|---|
| `Q1` | IRF9540N | `MOS_G` `DC_12` `DC_F` | P-MOS high-side, blocks reverse polarity |
| `D1` | BZX55C15V | `MOS_G` `DC_F` | gate zener |
| `R1` | 10 k | `MOS_G` `DC_F` | gate pull-down |
| `D2` | P6KE33A | `DC_12` `GND` | load-dump TVS |
| `C1` | 220 µ/50 V | `DC_12` `GND` | input bulk |
| `C2` | 100 n | `DC_12` `GND` | input HF |
| `C3` | 470 µ/35 V | `V5` `GND` | 5 V bulk |
| `C4` | 100 n | `V5` `GND` | 5 V HF |
| `R2` | 47 k | `DC_12` `BAT_DIV` | battery divider, top |
| `R3` | 10 k | `BAT_DIV` `GND` | battery divider, bottom |
| `R4` | 1 k | `BAT_DIV` `BAT_SNS` | series to the ADC pin |
| `C5` | 100 n | `BAT_SNS` `GND` | filter |
| `R5` | 220 Ω | `V3V3` `FUEL_SNS` | fuel sender excitation |
| `C6` | 100 n | `FUEL_SNS` `GND` | filter |
| `R6` | 10 k | `V3V3` `COOL_SNS` | NTC reference leg |
| `C7` | 100 n | `COOL_SNS` `GND` | filter |
| `R7` | 10 k | `LDR_SNS` `GND` | LDR divider |
| `C8` | 100 n | `LDR_SNS` `GND` | filter |
| `R8` | 1 k | `IGN_12` `IGN_LED` | opto-1 LED series |
| `R9` | 10 k | `IGN_SENSE` `GND` | pull-down |
| `C9` | 100 n | `IGN_SENSE` `GND` | filter |
| `OK1` | PC817B | `IGN_LED` `GND` `IGN_SENSE` `V3V3` | ignition isolation |
| `R10` | 1 k | `HALL_SIG` `HALL_LED` | opto-2 LED series |
| `OK2` | PC817B | `HALL_LED` `GND` `HALL_OUT` `V3V3` | speed-sensor isolation |
| `R11` | 10 k | `HALL_OUT` `GND` | opto-2 pull-down |
| `R13` | 1 k | `HALL_OUT` `HALL` | series to the GPIO |
| `D3` | P6KE6V2 | `HALL` `GND` | clamp on the speed line |
| `C10` | 100 n | `HALL` `GND` | filter |
| `R12` | 10 k | `TFT_BL` `GND` | backlight off at power-up (IO12 strapping) |
| `C11` | 100 n | `TRIP_BTN` `GND` | button debounce |
| `C13` | 100 n | `V3V3` `GND` | reference decoupling |
| `F1` | 5×20 2 A | `DC_IN` `DC_F` | fuse |
| `SW1` | 6 mm tactile | `TRIP_BTN` `GND` | on-board trip reset |
| `TP1`–`TP4` | — | `IGN_SENSE` `HALL` `BAT_SNS` `FUEL_SNS` | test points |
| `TP5` | — | *(no net)* | GPIO0 free pad — the DevKit does not bring IO0 to its headers |
